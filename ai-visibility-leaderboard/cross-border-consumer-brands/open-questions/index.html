— Source gaps

What the answers cite instead

The run returned 287 citations (251 unique URLs, all restored). Only 18 of them — 6.3% — landed on a tracked brand’s own domain; the citation layer is held by reviews, retailers and other third-party pages. That is a statement about this run’s answers, not about the value of any source type.

— Method

How to read this board

The questions. 50 constructed buyer questions in this category (44 non-price, 6 price-intent), written for this run; no question names a brand being measured. Price-intent questions are reported in their own layer and never enter the main board’s denominator.

The engines. ChatGPT, Perplexity and Gemini, run in grounded (live-search) form on 2026-11-24: 150 of 150 question–engine cells completed. Engines not run are not listed as absent — they were not measured.

The counting. A mention is the brand’s name (registered name or listed alias) appearing in an answer’s text, counted per answer. A citation counts when a returned link, followed through redirects, lands on the brand’s own domain. Rates are micro-averaged and always shown with their n and 95% Wilson interval: with n = 44 per engine, a gap of one or two answers sits inside the interval and is not a ranking.

Two reading notes. Per-engine counts here follow the run’s data files: Gemini surfaced 32 brands (an earlier read said 31), and 12 brands had an owned-domain citation (an earlier read said 11). “Lanshan” is a 3F UL Gear product line, not a registered alias this round; it never appeared without the brand name itself, so no count changes.

Baseline. This is the first run — the baseline every later run is read against.
